# 地震哨兵 (Earthquake Sentinel)

> 插上旧手机，它就是你的私人地震预警哨兵 —— 24 小时监听中国大陆官方地震预警，S 波到达前倒计时全屏告警。

## 功能

| 模块 | 说明 |
|------|------|
| **多源实时预警** | 同时订阅中国地震台网 (CENC)、四川省地震局、重庆市地震局 3 路官方 WebSocket，任一源收到报文即可触发 |
| **全屏倒计时告警** | S 波到达前强制全屏弹出，蓝/黄/橙/红四级预警 + 真实大陆预警语音播报 |
| **烈度阈值可调** | 2° 轻微有感 / 3° 明显有感（推荐）/ 4° 强烈有感，低于阈值仅通知栏提示 |
| **深色模式 OLED 省电** | 跟随系统 / 浅色 / 深色（#000000 纯黑）三档，AMOLED 屏黑色像素直接熄灭，防烧屏 |
| **地震历史记录** | 每条 EEW 持久化落盘，含未达阈值的小震远震，最近 7 天 / 最多 100 条，标注"已告警/备用源速报/已记录" |
| **备用探测源** | 全部 WebSocket 断连超时后，自动切换 USGS FDSN + Wolfx HTTP 双路 30s 轮询兜底 |
| **网络恢复自动重连** | WiFi ↔ 移动数据切换、出电梯恢复信号时，瞬间重连全部 WebSocket |
| **开机自启 + 后台保活** | 开机自动恢复监听；WakeLock 防止 CPU 休眠；厂商白名单引导（小米/华为/OPPO/vivo/三星） |
| **系统自检** | 一键检查通知/悬浮窗/定位/参考位置/监听/数据源/WakeLock/电池优化 8 项是否就绪 |
| **应用内更新** | 自动检测 GitHub Release 新版本，弹窗下载同签名覆盖安装 |

## 技术架构

```
┌─────────────────────────────────────────────────┐
│                    MainActivity                   │
│  ┌──────────┐  ┌──────────┐  ┌───────────────┐  │
│  │HomeFragment│  │HistoryFrag│  │SettingsFragment│  │
│  └──────────┘  └──────────┘  └───────────────┘  │
│             底部导航 (自绘 LinearLayout)          │
└─────────────────────────────────────────────────┘
         │                    │
    LocalBroadcast      startForegroundService
         │                    │
┌────────▼────────────────────▼──────────────────┐
│               EewService (前台服务)             │
│  ┌──────────────────┐ ┌─────────────────────┐  │
│  │ConnectionManager │ │    AlertManager     │  │
│  │ WebSocket×3     │ │ 解析→去重→告警触发   │  │
│  │ 重连/头条状态    │ │ 通知/备用源/历史记录 │  │
│  │ NetworkCallback  │ │                     │  │
│  └──────────────────┘ └─────────────────────┘  │
│  WakeLock / 位置刷新 / 新鲜度 / 通知通道        │
└─────────────────────────────────────────────────┘
         │                    │
    WebSocket (3路)      startActivity
         │                    │
┌────────▼────────┐  ┌───────▼──────────┐
│  Wolfx.jp 聚合   │  │ AlertActivity    │
│  (免Key免费)     │  │ 全屏倒计时+语音   │
└─────────────────┘  └──────────────────┘
```

**数据源**：全部经 [Wolfx](https://wolfx.jp/) 公共聚合转发（非官方，仅做转发，不生产数据），WebSocket 实时推送，免 Key、免费。

**关键设计决策**：
- 不用 Material BottomNavigationView（避免 AppCompat→MaterialComponents 主题污染），自绘 3 Tab LinearLayout
- Fragments 用 show/hide（不 replace）保留实例状态，深色模式 recreate 后自动恢复
- OkHttp 单例共享连接池（WebSocket 长连接 + 短连接更新检查复用同一客户端）
- 去重：按发震时间+震中(0.001°)+震级(0.1) 生成物理事件 Key，10 分钟窗口内跨源去重

## 构建

### 环境要求
- Android SDK 34
- JDK 17（推荐 Amazon Corretto 17）
- Gradle 8.9（wrapper 自带）

### 编译

```bash
# Debug
./gradlew assembleDebug

# Release（需配置签名）
# 在 local.properties 中添加：
#   dianguard.storePassword=xxx
#   dianguard.keyPassword=xxx
#   dianguard.keyAlias=dianguard
./gradlew assembleRelease
```

### 离线构建（本项目常用）
```bash
# 使用本地 JDK + SDK
JH_EXE=/path/to/jdk17/bin/java.exe
"$JH_EXE" -classpath gradle/wrapper/gradle-wrapper.jar \
    org.gradle.wrapper.GradleWrapperMain assembleRelease --offline --no-daemon
```

## 已知限制

- **数据源依赖第三方转发**：Wolfx.jp 是社区聚合项目，非官方基础设施。全断时有备用源兜底（USGS + Wolfx HTTP），但备用源不是实时预警。
- **国产 ROM 后台限制**：小米/华为/OPPO/vivo 等会强制杀后台进程。需手动将本应用加入自启动白名单 + 电池优化豁免（App 内有对应引导页）。
- **没有中国地震台网官方 API**：CENC 不向公众提供程序化接口，所有中国官方预警数据均经 Wolfx 转发。
- **位置精度**：使用设备 GPS/网络定位，非专有地震仪。震中距为近似值。
- **仅覆盖中国大陆**：数据源聚焦中国境内，不适用于台湾/日本等地区（这些地区的预警体系独立）。
